# ADR-002 — API REST con especificación OpenAPI 3.1 como contrato único

**Estado:** Aceptada  ·  **Contexto:** Portal de autoservicio de la fuerza de ventas (SIM-P05)

## Decisión
Toda API expone una especificación OpenAPI 3.1 versionada en el repositorio; los errores siguen RFC 7807 con correlation_id; versionado por ruta /v{n}.

## Consecuencias positivas
Contrato verificable y pruebas de contrato automatizables.

## Consecuencias negativas / riesgos
Disciplina de mantener la especificación como fuente de verdad.
