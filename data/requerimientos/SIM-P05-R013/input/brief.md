# Brief — Notificación de pedido confirmado y despachado

| Campo | Valor |
|---|---|
| Requerimiento | SIM-P05-R013 |
| Proyecto | SIM-P05 — Portal de autoservicio de la fuerza de ventas |
| Tipo | Funcional |
| Origen | Planeamiento de campaña (Planeamiento de Campaña) |
| Solicitante | Analista de Planeamiento de Campaña |
| Campaña objetivo | C2025-12 |
| Alcance geográfico | Guatemala |
| Canal | App móvil y web |
| Fecha de registro | 2025-11-21 |
| Complejidad estimada | 3 puntos |
| Aprobación formal del brief | No — aprobación verbal |

## Necesidad de negocio

La consultora no recibe confirmación cuando su pedido se registra ni aviso cuando sale a despacho.

## Resultado esperado

Mandar notificación (push en la app y correo) cuando el pedido queda confirmado y cuando se despacha, con el resumen y la fecha estimada de entrega.

## Restricciones conocidas

- Fecha de salida ligada al calendario de campaña (inamovible).
- Debe respetar las reglas de negocio: BR-010 Estados del pedido, BR-090 Canales de notificación y preferencia de la consultora.
