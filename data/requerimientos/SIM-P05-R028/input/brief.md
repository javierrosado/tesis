# Brief — Reserva de productos de lanzamiento con cupo por zona

| Campo | Valor |
|---|---|
| Requerimiento | SIM-P05-R028 |
| Proyecto | SIM-P05 — Portal de autoservicio de la fuerza de ventas |
| Tipo | Funcional |
| Origen | Planeamiento de campaña (Planeamiento de Campaña) |
| Solicitante | Analista de Planeamiento de Campaña |
| Campaña objetivo | C2026-07 |
| Alcance geográfico | México, Colombia |
| Canal | App móvil y web |
| Fecha de registro | 2026-07-02 |
| Complejidad estimada | 3 puntos |
| Aprobación formal del brief | No — aprobación verbal |

## Necesidad de negocio

Los lanzamientos se agotan en horas y las zonas pequeñas no alcanzan a pedir; Planeamiento quiere cupos por zona durante las primeras 24 horas.

## Resultado esperado

Durante las primeras 24 horas de la campaña, cada zona tiene un cupo del producto de lanzamiento; pasado ese tiempo, el remanente se libera para todos.

## Restricciones conocidas

- Fecha de salida ligada al calendario de campaña (inamovible).
- Debe respetar las reglas de negocio: BR-130 Preventa y reserva de lanzamientos, BR-021 Reserva de stock.
